# ADR 007: Store proposals as contract-shaped scope

## Status

Accepted.

## Context

A free-form proposal description is easy to send but difficult to review objectively at delivery time.

## Decision

Proposal scope separates a summary, deliverables, acceptance criteria and exclusions. Acceptance converts the commercial record to a project transactionally and materializes deliverables for delivery tracking.

## Consequences

- Delivery review can compare implementation against explicit promises.
- Scope exclusions remain visible instead of living only in messages.
- PulseOps still does not claim to generate or replace a legal contract.
