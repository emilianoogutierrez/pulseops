# ADR 005 — Product-specific interface over generic dashboard composition

## Status
Accepted.

## Decision
PulseOps uses a restrained operations interface with shared design tokens, stable navigation, dense tabular comparison, dedicated detail views and a global command search. Decorative gradients, repeated floating cards, oversized hero copy and inconsistent per-page visual rules are intentionally excluded.

## Why
An operations product is judged by how quickly a user can compare, decide and verify. Generic dashboard composition often optimizes screenshots rather than repeated use. The interface therefore maps visual hierarchy to PulseOps domain objects and actions rather than to reusable “SaaS dashboard” tropes.
